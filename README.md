# Companion (research prototype)

An on-device mental wellbeing chat for iPhone (iOS 27+, built for the iPhone 16 Pro). Everything runs on the phone:

- **Chat model:** LFM3-1.7B, 4-bit MLX (`LiquidAI/LFM3-1.7B-MLX-4bit`, ~945 MB, downloaded on first launch),
  run with mlx-swift-lm from the local `../mlx-swift-lm` clone (branch `lfm3`, which adds LFM3; not upstream yet).
  System prompt per message, by crisis level: `friend_short` (none) or `calm5` (check-in) from the 2026-11-02
  friend-voice evals, generated into `Companion/App/SystemPrompt.swift` by `scripts/export_prompts.py`. Temperature
  0.7, thinking off, `<think>`/`</think>` banned at sampling. Replies get the texting format in code
  (`Companion/App/Texting.swift`) after the crisis-resource filter.
- **Crisis layer (`CrisisKit/`):** every message is rated none / check-in / crisis by regex rules plus a RoBERTa
  classifier in Core ML before the chat model sees it (see `../crisis_layer/README.md` for how both were built and
  evaluated).
  - crisis: the fixed crisis screen opens (US: 988 call/text, Crisis Text Line, 911; elsewhere findahelpline.com
    and the local emergency number) and the chat model is skipped for that message
  - check-in: the reply gets a small "How are you holding up?" line with "I'm okay" / "I'm not safe", at most once
    every 10 messages or 30 minutes (halved after a crisis), unless a new kind of risk appears
  - every reply has crisis-resource sentences stripped (the model garbles them) and is blocked for unknown phone
    numbers, doses, very-low-calorie plans, concealment tips and validation of self-harm

**Not a medical device.** Not validated with real people in crisis; crisis resources must be verified and maintained
by people, and clinician review is needed before anyone else uses it.

## Build and run on your iPhone

1. `scripts/fetch_models.sh`: puts the crisis classifier (~250 MB, not in git) into `Companion/Resources/`, copied
   from `../crisis_layer/coreml` or downloaded from the private Hugging Face repo `pranaybeela/crisis-classifier`.
2. `xcodegen generate`: writes `Companion.xcodeproj` from `project.yml` (the project file is not in git).
3. Open `Companion.xcodeproj`, select the Companion target → Signing & Capabilities → choose your team (a free
   Apple ID works), plug in the iPhone, select it as the run destination, and press Run. On the phone, trust the
   developer certificate in Settings → General → VPN & Device Management the first time. MLX does not run in the
   iOS Simulator.
4. The first launch downloads LFM3 (~945 MB) over the network; after that the app works offline.

`CrisisKit` has its own tests (`cd CrisisKit && swift test`): the Swift rules, reply filter and policy against the
Python originals on 308 test messages and 600 LFM3 replies. With `CRISIS_COREML_DIR=../../crisis_layer/coreml` it also
runs the Core ML classifier and compares tokens and probabilities with the PyTorch model.

The regex patterns in `CrisisKit/Sources/CrisisKit/RulesData.swift` and the test fixture are generated by
`../crisis_layer/export_swift.py`; change the rules in Python and regenerate.

## UI work without the phone (Simulator demo)

The views depend on the small `ChatModel` protocol (`Companion/Shared/ChatModel.swift`), not on `AppModel` directly.
`PreviewChatModel` (`Companion/Preview/`) implements it with canned conversations and scripted replies, so SwiftUI
previews and the **CompanionDemo** target run without MLX. CompanionDemo has no chat model and no crisis layer; it is
for looking at the UI only and must never ship.

```sh
xcodegen generate
xcodebuild -project Companion.xcodeproj -scheme CompanionDemo -destination 'platform=iOS Simulator,name=iPhone 16 Pro' \
  -derivedDataPath build-demo CODE_SIGNING_ALLOWED=NO build
```

Pick a screen with launch arguments: `-demo conversation|answered|streaming|replying|empty|loading|preparing|failed`,
`-demoCrisis YES` (crisis screen on top), `-acceptedNotice NO` (first-launch notice), `-AppleLocale en_US` (US
resources on the crisis screen). In the demo, a message containing "demo crisis" shows the crisis card.
